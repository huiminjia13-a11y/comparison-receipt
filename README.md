# 今晚的比较小票

把刚才那口比较打成一张热敏小票，然后归档或撕掉。不是测试，不算命。给那一口一个出口和仪式，不评价你。

## 慧敏怎么打开（本地）

1. 打开这个文件夹：`outputs/comparison-receipt/`
2. 用浏览器打开 **`index.html`**（双击，或拖进 Chrome / Safari）
3. 点「开始打票」

不需要安装、不需要账号、不上网也能玩。建议手机竖屏。

右上角「声音 开 / 关」，默认开。打印、盖章、撕票、猫的咕噜和脚步都走这个开关；刷新会记住。

比较对象进入时默认是「过去的自己」，可以改。感觉栏必填；灰按钮会让输入框轻抖，并提示「写一个词就行，比如：酸」。

打印机旁趴着一只狸花猫。不说话、不评分、不能喂。第一次可以给它起名或跳过。归档后它会转过去对着抽屉；撕掉时贴地溜走，回首页再趴回来。

本周抽屉顶上是结算单：比较次数、归档、撕掉（撕掉只计数、不留内容），以及最常对象 / 时段 / 感觉。只列事实。

归档或撕掉之后，最后才有分享。图和句子是「今晚的账单」或「今晚撕了一张」，对象和感受打成 ████。没有排行榜。
