# 今晚的比较小票

把刚才那口比较打成一张热敏小票，然后归档或撕掉。不是测试，不算命。给那一口一个出口和仪式，不评价你。

## 在线打开（手机 / 电脑同一链接）

GitHub Pages（`main` 根目录）：

**https://huiminjia13-a11y.github.io/comparison-receipt/**

手机浏览器直接打开；电脑 / 云桌面同一地址。无账号。

## 慧敏怎么打开（本地）

1. 打开这个仓库根目录（`index.html` 就在根上）
2. 用浏览器打开 **`index.html`**（双击，或拖进 Chrome / Safari）
3. 点「开始打票」

不需要安装、不需要账号、不上网也能玩。建议手机竖屏。

右上角「声音 开 / 关」，默认开。打印、盖章、撕票、猫的咕噜和脚步都走这个开关；刷新会记住。

比较对象进入时默认是「过去的自己」，可以改。感觉栏必填；灰按钮会让输入框轻抖，并提示「写一个词就行，比如：酸」。

打印机旁趴着一只中华田园猫（狸花）：灰黄底、深褐虎斑、琥珀眼、瘦长身子。不说话、不评分、不能喂。第一次可以给它起名或跳过。出票时抬头看纸；归档后半转得意对着抽屉；撕掉时压耳贴地溜走；回首页再趴回来。`prefers-reduced-motion` 时改为甩尾 / 淡出。

本周抽屉顶上是结算单：比较次数、归档、撕掉（撕掉只计数、不留内容），以及最常对象 / 时段 / 感觉。只列事实。

归档或撕掉之后，最后才有分享。图和句子是「今晚的账单」或「今晚撕了一张」，对象和感受打成 ████。没有排行榜。

## 云桌面 / 电脑怎么打中文（离线）

手机一般自带中文输入法，直接打就行。Cursor 云桌面或没有装中文 IME 的电脑，用页面里的离线入口：

1. **点常用词**：感觉栏下方有「酸 / 空 / 来不及…」和短句；「是谁」「对方有什么」也有词可点。点一下就填进输入框。
2. **拼一句**：需要更长时，可先点一个词，再改；或再点另一个词覆盖。
3. **拼音候选（感觉栏）**：若云桌面只能打英文，在感觉栏输入拼音（如 `suan`、`kong`、`weiqu`），下方会出现离线候选，点中文填入。字典很小，只覆盖常用感觉词，不上网。
4. **粘贴**：在手机打好中文 → 复制 → 粘贴到云桌面输入框。页面已保留 IME composition 保护，有系统输入法时也不会打断组字。

全程本地、无网络请求。
