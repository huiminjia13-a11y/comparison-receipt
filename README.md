# 今晚的比较小票

想到谁，就打一张热敏小票。盖章。归档，或撕掉。比较可空。不服、惦记、想赢，都能入账。不是测试，不算命。不疗愈你。

## 慧敏怎么打开（本地）

1. 打开这个仓库根目录（`index.html` 就在根上）
2. 用浏览器打开 **`index.html`**（双击，或拖进 Chrome / Safari）
3. 点「开始打票」

不需要安装、不需要账号、不上网也能玩。建议手机竖屏。

右上角「声音 开 / 关」，默认开。打印、盖章、撕票、猫的咕噜和脚步都走这个开关；刷新会记住。

入口是「今天你想到了谁」。前公司、那个 offer、过去的自己、突然冒出来的人、朋友、前任……都可以。进入时选中「过去的自己」，可以改。选了一个人，就能打票。感觉栏可不填：想、气、又气又想、不服，都能写在同一行。

填完「想到了谁」之后，可以再写一口比较：对方有什么（那个 offer / 头衔 / 看起来很确定的人生 / 胆子 / 钱……）。这一口可以空着。停留多久也可以不选。空着也能打票。写完仍可归档或撕掉。

出票会盖章：已付无法退款 / 今晚结算 / 还在想 / 不服——按感觉与票号轮换。票面一句：**比较不是病。是燃料。今晚结算 · 已付无法退款。**

打印机旁趴着一只中华田园猫（狸花）：灰黄底、深褐虎斑、琥珀眼、瘦长身子。不说话、不评分、不能喂。第一次可以给它起名或跳过。出票时抬头看纸；归档后半转得意对着抽屉；撕掉时压耳贴地溜走；回首页再趴回来。`prefers-reduced-motion` 时改为甩尾 / 淡出。

本周抽屉顶上是结算单：出票次数、归档、撕掉（撕掉只计数、不留内容），以及最常想到 / 时段 / 感觉。只列事实。周日会提示「本周总票」；抽屉里随时可点「导出本周总票」，生成账单式长图（次数、最酸的一天等），默认同公开打码。

出票完成后可点「一键晒图」：下载热敏风 PNG（日期、票号、今晚第几张、章与金句）。默认**公开安全空票脸**；需要时再切「本机完整」。归档 / 撕掉后仍可再晒。不用自己裁屏。

入口与票旁会显示今晚聚合：「本机今晚 N 张 · 广场今晚约 M 人 · X% 选了『酸』」。只统计人数与词桶占比，**不展示任何人的票面**。广场数字是本机日历夜种子 + 你本机贡献的氛围估算，不是已核实的全球实况。小票正文只存在本机。

## 云桌面 / 电脑怎么打中文（离线）

手机一般自带中文输入法，直接打就行。Cursor 云桌面或没有装中文 IME 的电脑，用页面里的离线入口：

1. **点常用词**：感觉栏下方有「想 / 气 / 不服 / 又气又想…」和短句；「是谁」、可选的「比一口」也有词可点。点一下就填进输入框。再点另一个感觉词，会接在同一行。
2. **拼一句**：需要更长时，可先点一个词，再改；或再点另一个词覆盖。
3. **拼音候选（感觉栏）**：若云桌面只能打英文，在感觉栏输入拼音（如 `xiang`、`qi`、`bufu`），下方会出现离线候选，点中文填入。字典很小，只覆盖常用感觉词，不上网。
4. **粘贴**：在手机打好中文 → 复制 → 粘贴到云桌面输入框。页面已保留 IME composition 保护，有系统输入法时也不会打断组字。

全程本地、无网络请求。
